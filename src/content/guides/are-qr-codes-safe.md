# Are QR Codes Safe? How to Avoid QR Code Scams

QR codes are convenient, but like any link, they can be misused. The code itself is just a picture. The risk comes from where it sends you. This guide explains how QR code scams work and how to protect yourself.

## Is scanning a QR code dangerous?

Scanning a code is not harmful by itself. Your phone reads the pattern and shows you the link or text inside. The danger starts if you open a malicious link, enter private details on a fake page, or install something you should not. Used carefully, QR codes are safe.

## How QR code scams work

Scammers rely on the fact that people cannot read a QR code by eye. Common tricks include:

- **Sticker overlays.** A fake code is stuck over a real one on a poster, parking meter or restaurant table.
- **Fake login pages.** The code leads to a page that looks like a bank or social media login and steals your password.
- **Urgent messages.** A code on a letter or email claims you must act quickly to avoid a penalty or claim a prize.
- **Fake payment requests.** A code that asks you to pay or send money to a stranger.
- **Unwanted downloads.** A link that tries to make you install an app you did not ask for.

This kind of attack is sometimes called QR phishing.

## How to scan safely

1. **Check the link preview.** Most phone cameras show the web address before you open it. Read it carefully. If it looks strange, misspelled or unrelated, do not tap it.
2. **Look at the source.** Be suspicious of codes in random emails, unexpected letters or stickers on public property.
3. **Check for tampering.** If a code looks like a sticker placed over another, do not scan it.
4. **Never enter sensitive details** such as passwords, card numbers or one-time codes on a page you reached through an unknown code.
5. **Do not install apps** from a QR code unless you started the process and trust the source.
6. **Use official apps for payments.** Open your bank or payment app yourself instead of following a link.
7. **Keep your phone updated.** Security updates help block malicious pages.

## If you create QR codes

You also have a part in keeping people safe:

- Link only to pages you own and control.
- Use a secure address that starts with https://.
- Add a short label so people know what the code does.
- Check printed codes regularly to be sure no one has covered them.
- Do not use a link-shortening service you do not trust, since the destination could change.

## What to do if you scanned a suspicious code

- Close the page without entering anything.
- If you entered a password, change it right away, and change it anywhere else you use it.
- If you shared card details, contact your bank immediately.
- Run a security scan on your phone if you installed anything.

## Summary

QR codes are safe when you scan with care. Read the link before you open it, be wary of unexpected codes, and never give out private details on a page you reached by scanning. If you make QR codes, use secure links you control, so people can trust them.
