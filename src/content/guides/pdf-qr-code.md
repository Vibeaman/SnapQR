# How to Create a QR Code for a PDF File

Sometimes the thing you want to share is a document: a menu, a brochure, a price list, a flyer, a CV or a product manual. A QR code lets people open the file on their phone without typing a long address or downloading anything first.

## How it works

A QR code cannot contain a whole PDF file. Instead, it holds a link to where the PDF is stored online. When someone scans the code, their phone opens that link and shows the document. So the process has two parts: put the PDF online, then turn its link into a QR code.

## Step 1: Upload your PDF

You need a place to host the file. Common options:

- **Your own website.** The best choice if you have one, since you control the address.
- **Google Drive.** Upload the file, then change the sharing setting to "Anyone with the link can view".
- **Dropbox or OneDrive.** Create a public share link for the file.

Whichever you choose, copy the final share link. Open it in a private browser window to confirm anyone can view it without signing in.

## Step 2: Prepare the PDF for phones

Most people will read the file on a small screen, so make it easy:

- Keep the file size small, ideally under a few megabytes, so it loads on slow data.
- Use a readable font size.
- Avoid tiny text in wide tables.
- Make sure the first page shows the most important information.
- Compress large images before exporting.

## Step 3: Generate the QR code

1. Open SnapQR and paste the PDF link into the input box.
2. Choose dark colors on a light background.
3. Generate and download the image.

If your link is very long, shorten it first or place the PDF on your own website with a short address. Shorter links make cleaner, easier-to-scan codes.

## Step 4: Label it clearly

Tell people what they will get. Examples:

- "Scan to view our menu"
- "Scan to download the brochure"
- "Scan to see the price list"

If the file will download automatically instead of opening, mention that too, so people are not surprised.

## Step 5: Test on real devices

Scan the code with at least two phones and confirm the document opens properly. Check that the pages are not cut off and that the text is readable. If you are using Google Drive, test while signed out to be sure the link does not ask for permission.

## Updating the file later

If your PDF is on a service like Google Drive, you can often replace the file while keeping the same link. This depends on the service, so check how yours handles updates before you print many copies. Hosting on your own website gives you the most control, because you can replace the file at the same address at any time.

## Things to avoid

- Linking to a private file that requires login
- Uploading a huge file that takes a long time to load
- Using a temporary or expiring link
- Printing the code before testing it

## Summary

To make a PDF QR code, host the file online, copy its public link, and turn that link into a code. Keep the file small, label the code clearly, and test it before you print.
