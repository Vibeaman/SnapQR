# How to Create a QR Code for a Restaurant Menu

A QR code menu lets customers view your food and prices on their own phones. It cuts printing costs, makes updates easy, and keeps tables tidy. Here is how to set one up properly.

## Step 1: Put your menu online

A QR code only points to something that already exists online. You have a few options:

- **A PDF menu.** Export your menu as a PDF and upload it to your website or a file hosting service that gives you a public link.
- **A menu page on your website.** This is best, because text loads quickly and can be updated any time.
- **A social media page.** Some small food businesses link to a pinned post or catalogue. This works, but a dedicated page looks more professional.

Whatever you choose, open the link on a phone before you continue. Make sure the text is readable without zooming.

## Step 2: Make the menu phone-friendly

Most customers will scan with a phone, so design for a small screen:

- Use large, clear text.
- Keep file sizes small so the menu loads on slow mobile data.
- Avoid very wide tables that need sideways scrolling.
- Show prices clearly next to each item.
- List allergens or special notes where relevant.

## Step 3: Generate your QR code

1. Copy your menu link.
2. Paste it into SnapQR.
3. Generate and download the code.

If your link is long, consider a short page address on your own domain, which makes the code simpler and easier to scan.

## Step 4: Print and place it well

- Print the code at least 3 cm wide for table use.
- Add a line such as "Scan to view our menu" so no one is confused.
- Place codes on table stands, menu holders, the counter and the entrance.
- Use matte printing or a matte laminate. Glossy surfaces reflect light and can make scanning difficult.
- Keep a few paper menus for guests who prefer them or have older phones.

## Step 5: Keep it up to date

Because the code points to a link, you can change the menu content any time by updating the file or page at that link, as long as the web address stays the same. Update prices and sold-out items promptly, since customers trust what they see on screen.

## Benefits of a QR menu

- Saves money on reprinting when prices change
- Easy to update daily specials
- Fewer worn or dirty paper menus
- Works for takeaway and delivery flyers too

## Things to watch out for

- Test the code at your actual tables, in your actual lighting.
- Do not hide your menu behind a sign-in or a slow website.
- Make sure the code is not covered by condensation, stickers or decorations.

A well-made QR menu feels modern and convenient. Get the link right, print the code at a good size, and test it before your next busy service.
